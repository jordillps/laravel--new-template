🛡️ GUÍA DE RESET DE LA APLICACIÓN LARAVEL + SHIELD

⚠️ Problema Común:
Cuando ejecutas `php artisan migrate:fresh --seed`, los permisos de Filament Shield se pierden y necesitan ser regenerados manualmente.

✅ SOLUCIONES DISPONIBLES:

🚀 Opción 1: Comando Automático (RECOMENDADO)
Usa el comando personalizado que hace todo automáticamente:

php artisan app:reset --force

Este comando ejecuta en orden:
1. migrate:fresh --seed
2. shield:generate --all (con confirmaciones automáticas)
3. role:assign-all-permissions super_admin
4. Limpia todas las caches

🔧 Opción 2: Pasos Manuales
Si prefieres hacerlo paso a paso:

# 1. Reset de base de datos
php artisan migrate:fresh --seed

# 2. Generar permisos de Shield (responder: 0, enter, 0)
php artisan shield:generate --all

# 3. Asignar permisos al super_admin
php artisan role:assign-all-permissions super_admin

# 4. Limpiar caches
php artisan config:clear && php artisan cache:clear

📋 Respuestas para shield:generate --all:
Cuando ejecutes `shield:generate --all`, responde:
- Panel: 0 (admin)
- Generate both: enter (yes - default)
- What to generate: 0 (policies_and_permissions)
